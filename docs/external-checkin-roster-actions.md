# 外部签到名单去重、删除与管理员帮签

## 用户本次确认的行为

- 导入时，所有配置字段完全一致的记录自动去重；与已有名单完全一致时跳过。沿用文本全半角规范化与首尾空白处理规则。
- 核验字段组合相同、其他资料不同的记录继续展示完整对比。管理员可保留一条、删除本次导入候选，或删除本组全部待导入记录。只剩一条候选时保留该条；全部待导入记录删除时不新增，并保留该组已有名单。现有名单的实际删除在名单操作列完成。
- 导入窗口的删除只影响当前预检选择，支持恢复；取消窗口不写入。所有选择在服务端重新校验并原子提交。
- 名单操作列提供单人删除，确认时展示核验信息和签到状态。已签到记录也可删除；删除后无法继续通过该条名单签到。删除最后一条名单时自动暂停会议。
- 管理员可以为未签到嘉宾帮签，即使自助签到暂停或不在时间窗口内。使用服务端当前时间，保留嘉宾原资料，不虚构现场填写值。重复帮签幂等，不覆盖首次时间。
- 帮签及删除只允许具备外部签到写权限且拥有全部会议范围的管理员，记录操作人审计。删除与嘉宾扫码使用同一会议锁；若确认期间名单版本或目标签到状态变化，拒绝过期删除并要求重新确认。

## 验证与发布

测试自动去重统计、混合重复与不同核验组合、删除部分/全部候选、摘要与选择篡改；真实 API 测试鉴权、跨会议隔离、删除与扫码竞争、版本过期、帮签并发幂等、首次时间保留、删除后查询与统计以及最后一条删除自动暂停。浏览器验收完整管理员操作。

不增加数据库结构，不修改订单、支付、原会议报名流程。完成验证后按用户要求直接部署上线，并以临时合成数据复验和清理。

## 本地验证结果

- 共享规则与表格解析 45 项通过，包括 5,000 条相同记录和 5,000 条同核验组合不同资料的批次。
- 真实 NestJS + PostgreSQL 17 项通过，涵盖权限、跨会议隔离、自动去重、整组不导入、帮签与扫码并发、删除确认过期、删除与扫码竞争、审计及空名单自动暂停。
- 后台类型检查、API 与后台构建通过。
- 合成数据浏览器验收通过：自动去重计数、差异记录逐条删除/恢复与整组不导入、取消不写入、帮签确认及取消、已签到/未签到名单删除、统计同步；帮签后重复扫码保留原时间，删除后扫码不能匹配。

人工验收：进入外部会议的“管理签到”。导入文件后点击“预检导入”，相同资料显示自动去重数量，有差异的组可保留或删除；在嘉宾名单每行右侧点击“帮签”或“删除”，核对嘉宾信息后确认。
