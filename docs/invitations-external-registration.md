# 公众号后台配置与外部会议

## 范围

- 邀请函可关联系统会议，也可独立创建外部会议，不向小程序会议列表插入占位会议。
- 共享草稿中的报名设置支持小程序会议、外部 HTTPS 链接和隐藏报名；发布后所有旧个人链接同步读取设置。
- 旧邀请函未配置报名设置时，继续使用原关联会议的小程序报名。外部报名不附带嘉宾姓名、邀请标识或系统登录态。
- 外部入口只负责跳转，不读取第三方表单结果、不自动生成系统报名记录或支付订单。
- 公众号配置独立权限 `invitation:settings`，复用已有 AES-GCM 配置加密工具。密钥仅用于服务端微信请求，不回显、不写审计内容。
- 配置支持启停、AppID、替换 AppSecret、域名校验文本和连接检测；数据库配置优先，无数据库配置时兼容原环境变量。修改配置后无需重启。
- 连接检测仅代表接口凭据可用，不代表微信域名设置或真实分享卡片验收通过。

## 验收

- 验证旧会议兼容、外部会议创建/发布、报名方式切换、外部 URL 拒绝危险协议、两个个人链接共享发布更新。
- 小程序报名只接受与已发布报名设置匹配的会议归因，不改变价格、支付或报名成功规则。
- 验证配置权限、空密钥保留、切换 AppID 必须提供新密钥、并发版本冲突、密钥加密且 API/日志/审计不回显。
- 验证凭据更新后票据缓存隔离、微信错误脱敏、校验文件只允许固定名称和纯文本。
- 手机与桌面浏览器检查新建表单、报名配置、公众号设置。生产真实公众号检测由用户输入配置后执行。

## 使用路径

1. 后台「专属邀请函」右上角「公众号配置」填写 AppID、AppSecret，可上传微信下载的域名校验文件。保存后执行「检测连接」。此入口需要 `invitation:view` 和 `invitation:settings` 权限。
2. 在微信公众平台完成页面显示的 JS 接口安全域名配置，并按微信要求配置服务器 IP 白名单。后台保存不能代替公众平台的域名授权。
3. 「新建会议邀请函」选择「系统会议」或「外部会议」。系统会议从已有会议选择；外部会议独立填写名称、时间和地点，不必先在小程序建会议。
4. 邀请函「报名入口」支持小程序会议、外部 HTTPS 链接和不显示报名。按钮文字可改。保存草稿不会影响公开版本，发布后所有已生成链接同步更新。
5. 公众号 AppSecret 留空表示保留原值，修改 AppID 时必须同时填写新密钥。公众号配置保存即生效，不需要发布邀请函或重启服务。

## 数据与回退

- 数据库仅将邀请函的会议关联改为可空，并新增公众号配置表；不修改价格、支付和报名成功规则。
- 配置密钥复用项目 AES-256-GCM 加密，运维需保留现有加密密钥（独立配置密钥或 JWT 兼容密钥）及其备份，不能随意替换后丢弃旧密钥。
- 一旦创建独立外部会议，旧版代码不能保证处理空会议关联。回退应保留可空关联兼容逻辑，不得通过删除外部会议、丢弃配置或强制恢复非空约束回退。
