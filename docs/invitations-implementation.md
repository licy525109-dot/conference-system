# 专属邀请函

本次经用户授权新增会议邀请函模块，不新增优惠、免支付或独立报名流程。

## 数据与发布

- 每场会议只有一个 InvitationCampaign。draftJson 和 publishedJson 均使用共享的 InvitationContent 契约；发布在事务中整体替换 publishedJson 并递增 publishedRevision。
- ConferenceInvitation 仅保存受邀人、称谓、负责人、可选的公开名单行标识及随机链接标识，不保存内容快照，不绑定发布版本。
- 公共接口只返回已发布内容和当前受邀人的称谓；不返回后台备注、其他受邀人、手机号或工作人员信息。
- 在线前台每 20 秒读取最新内容，页面恢复可见时立即更新。邀请停用、会议下架后停止展示。接口及 HTML 禁止缓存。
- 公开嘉宾和拟邀名单独立于个人邀约记录。

## 界面与入口

- 注册 ds-invitation 组件，经 Render Governor 生成节点，邀请页面和后台预览共用同一 Vue 组件。
- 每场会议可一键应用潮汐朱红、山水青玉、当代艺文三种视觉预设，联动主视觉、排版、配色和动效；精细调整折叠收纳。两张抽象艺术底图为生成素材，不代表真实会场照片。后台手机预览复用正式组件，支持重播动效。
- 新建时带入会议名称、时间、地点，无封面时提供默认主视觉。「保存并发布」先保存草稿，再用返回的最新草稿版本发布，保留冲突校验及全链接更新确认；也可只保存草稿。
- 分享标题及摘要支持 `{姓名}`、`{称谓}`、`{会议名称}`。默认 `{姓名}专属邀请函`，后台可输入预览姓名。共享解析器做单次字面替换，不执行表达式；服务端 HTML、页面标题、分享预览及微信 SDK 使用相同结果。
- 公共 H5 是现有 Admin Vite 构建中的独立入口，不加载后台登录或后台页面。Nest 在 /i/:token 输出含分享元信息的入口 HTML，并提供 /invitation-assets 静态资源。
- 正式邀请地址固定使用配置的 guanchaohuiji.com 品牌域名，禁止使用第三方短链作为对外邀请地址。
- 微信图文卡片由认证服务号 JS-SDK 配置；工作人员通过微信右上角分享。历史聊天卡片缓存不保证刷新，打开后的页面统一刷新。
- 报名按钮使用开放标签进入已发布的小程序报名页；外部浏览器提供二维码，避免将第三方中转域名作为邀请页地址。

## 章节导航配置（2026-10-01）

- 入口为「视觉与分享 → 章节导航」。支持整栏显示开关、单项显示开关、导航名称、上下排序、吸顶开关以及一键按正文顺序排列。导航排序不改变正文模块顺序，隐藏导航项也不隐藏正文。
- `InvitationContent.navigation` 使用共享 JSON 契约，包含 `enabled`、`sticky`、`items`；条目绑定稳定的 `moduleId`，自定义名称最长 40 字，留空使用模块标题。旧邀请函没有此字段时，默认显示并吸顶，按现有模块顺序生成。
- `normalizeInvitationNavigation` 清理无效、重复和已删除模块的引用，新模块自动追加到末尾；隐藏或暂无可展示内容的模块不生成跳转。所有条目隐藏时不保留空导航栏；整栏关闭不会删除已配置的名称、顺序和显示状态。
- 后台预览与嘉宾页复用相同的可见模块和导航计算逻辑，手机端横向滚动；停靠偏移随吸顶开关更新。配置沿用 `invitation:content` 编辑和 `invitation:publish` 发布权限，不新增权限或数据库迁移。
- 草稿与发布内容保持隔离，发布后所有已生成的个人链接同步，无需重新发链接。本轮未改会议内容、整体视觉或任何支付/订单/报名逻辑。

## 封面画布与内容模块（2026-10-01）

- 「视觉与分享 → 封面设计」区分成品海报与排版模板。成品海报保留原图比例，不裁剪、不叠加模板标题、日期或品牌。图片字段显示实际像素尺寸；建议 1080 × 1920 px（9:16），JPG/PNG/WebP，单图不超过 2MB。
- 封面最多 12 层可选文字。支持拖动定位、方向键微调、百分比位置/宽高、原图像素字号、黑体/宋体/楷体、颜色、加粗、斜体、下划线和对齐；每层可隐藏或删除。画布整体等比缩放，长文本在限定框内自动缩小。
- 图层支持 `{姓名}`、`{称谓}`、`{单位}`、`{职务}`、`{会议名称}`、`{会议时间}`、`{会议地点}`，以及自定义文字。单位、职务来自已匹配的公开名单行，同名不擅自绑定；无匹配时为空。分享变量仍为姓名、称谓和会议名称三项。
- 上传海报后，图片内已包含的会议文字无需重复填写；时间、地点和正文不再是发布必填，会议名称也允许留空。发布仍需有效封面；会议文字在模板模式或相应图层、模块中按配置显示。
- 「会议内容」使用独立模块列表和大编辑区。最多 24 个模块，可新增图文、图片、邀请正文、亮点、议程、嘉宾、公开名单、赴约信息；支持标题、上下排序、隐藏与删除。结构化模块同类型最多一个，图文和图片可重复。
- 图文编辑复用项目已有 WangEditor 5.1.23，支持字体、字号、粗体、斜体、下划线、删除线、前景/背景色、对齐、列表、引用、链接、图片、撤销/重做及全屏。上传使用邀请函自身权限，不额外索取素材库权限。失焦同步正文，避免快速保存遗漏末次编辑；字体引号在编辑器文本标记层标准化，避免该版本 HTML 序列化丢失字体。
- 持久化为有界结构化富文本节点，不信任编辑器原始 HTML。服务端对白名单标签、属性、样式、图片及链接重新校验；嘉宾页与后台预览共享安全序列化与同一个画布组件。脚本、事件处理器、任意定位 CSS、可执行/协议相对链接不会进入公开渲染。
- 「视觉与动效」支持上浮、渐入、幕布展开或无章节动效；封面静态、淡入或聚焦展开；连续长页或章节停靠；200–1200ms 时长。系统减少动态效果优先，关闭动画和章节吸附，不强制劫持触摸手势。
- 新字段位于共享 JSON 内容，不新增数据库表或迁移。旧发布内容自动补默认模块和模板模式。保存草稿不改变旧链接，发布整体替换共享内容并保留修订号冲突检查。

## 扩展模块、素材与主题（2026-10-01）

- 内容模块增加视频、音频、轮播图、标签页、地图、图标链接组和内容搜索，共 15 种类型；展示模块可重复，仍保持总上限 24 个。议程可独立配置分享嘉宾头像；嘉宾支持最长 10000 字的分段介绍及网格/列表排版。
- 编辑器采用模块导航、内容/样式分栏、桌面实时嘉宾预览。样式区独立配置模块底色、文字色、强调色、背景图片、间距和标题对齐；手机端收纳模块导航，保留完整编辑与预览入口。
- 拟邀名单可按姓名拼音、单位、职务升降序，空值排后；也可上下移动或输入绝对位置。切换手动排序时物化当前顺序，不丢失行 ID。公开展示、搜索及本人跨页定位均使用同一排序结果。
- 图片、音视频和字体统一支持 HTTPS 地址、本地上传和素材库选择。上传复用现有素材库及审计日志，自动记录会议用途；素材库支持搜索、分类与分页。新接口为 `/api/admin/invitations/campaigns/:id/assets` 的 GET/POST，均校验邀请内容权限和会议授权。
- 没有 `material:view` 的邀请编辑员仅能选择本人上传或当前会议用途的素材；有素材查看权限才可复用全库。不额外授予全库管理权。删除素材时检查邀请函草稿和已发布内容引用，防止旧链接的图片、媒体或字体被误删。
- 上传限制：JPG/PNG/WebP 2MB；MP4、MP3/WAV/OGG 20MB；WOFF2/WOFF/TTF/OTF 5MB。服务端校验扩展名、大小和文件头并使用规范 MIME，不信任浏览器提供的类型。图片尺寸仍在后台显示。
- 全局主题支持四套色板、主题色/点缀色/页面底色/正文色、背景图与透明度、缓慢平移/呼吸动态背景、页面字体和字号。字体上传需确认网页使用授权；支持一键统一封面图层、正文和模块字体。图片内已烘焙的文字不能替换；外链字体需要来源服务器允许 CORS。加载失败回退系统字体，后台预览显示提示。
- 轮播使用 Swiper 14.3.0，支持滑动、淡入、旋转层叠、翻面、手势、进度滑块、可选自动播放和暂停。此处的滑块/旋转是轮播交互，不是任意元素动画时间轴。音视频使用原生控件，不自动播放，支持移动端行内视频及失败提示。
- 地图使用延迟加载的 Leaflet 1.9.4 和 OSM 标准地图；坐标为 WGS84，导航通过地址打开高德搜索，避免把 WGS84 直接当作高德坐标。瓦片请求只发送站点 origin，不泄露邀请 token/姓名；页面其他请求的隐私策略不变。地图依赖外部网络，OSM 不提供 SLA，正式上线仍需国内网络与微信真机验收。
- 新字段仍为共享 JSON，不新增数据库迁移。后台/嘉宾共用受治理的渲染组件，减少动态效果时关闭背景运动和轮播特效。异步构建资源使用相对 chunk 路径，兼容后台 `/assets/` 与嘉宾 `/invitation-assets/`；公开上传资源跟随邀请站点 origin，后台预览使用配置的 API origin。

设计与实现参考：[Webflow Style panel](https://help.webflow.com/hc/en-us/articles/33961362040723-Style-panel-overview)、[Webflow Navigator](https://help.webflow.com/hc/en-us/articles/33961320786451-Navigator)、[Framer custom fonts](https://www.framer.com/help/articles/how-to-add-custom-fonts/)、[Swiper Vue](https://swiperjs.com/vue)、[Leaflet quick start](https://leafletjs.com/examples/quick-start/)、[OSM tile policy](https://operations.osmfoundation.org/policies/tiles/)。未引入通用拖拽建站插件或任意脚本执行。

## 权限与报名

- invitation:view / write / content / publish / all / access 分别负责查看、维护个人邀请、编辑内容、发布、查看所有邀约和分配会议权限。
- 除全局访问权限账号外，按 InvitationCampaignMember 校验每场会议的授权，普通邀约人员只能管理自己创建的邀请。
- 订单创建事务中验证邀请有效性和会议匹配，保存 invitationId。报名状态从支付后的 Registration 读取，不修改支付确认逻辑。
- 专属邀请入口使用直接报名，暂不显示加入购物车，避免跨会议购物车结算丢失邀请来源；普通报名入口不受影响。
- 姓名不作为认证，邀请不提供免费资格，金额仍由后端重算。

## 名单导入与定位

- 独立「公开名单」页支持 XLSX、XLS、CSV、TSV，文件上限 5MB，最多公开 500 行；浏览器 Web Worker 使用打包的 SheetJS 0.20.3 解析，15 秒超时，不将原始工作簿上传到服务器。UTF-8 CSV 失败时尝试 GB18030。
- 自动扫描前 20 行识别表头和姓名、单位、职务常见别名；可切换工作表、表头行及列映射。预览只展示所选公开列，手机号等未选列不会写入邀请内容；请工作人员在确认导入前检查公开列。
- 默认合并，可明确选择替换。缺少姓名、字段超长的行列出原因；超限不截断；同姓名、同单位、同职务的重复行合并并计数；同姓名同单位但职务冲突、或与现有多条同单位同名记录重合时阻止自动合并，需工作人员先确认。
- 行标识按规范化姓名和单位稳定生成，重导入复用已有行标识。姓名相同但不同单位保留为不同记录，生成/修改邀请时要求明确选择。唯一姓名自动匹配，无匹配仍可生成邀请但不显示定位按钮。
- 嘉宾页展示姓名、单位、职务表格，每页 20 人，可搜索。「查看我的位置」清除搜索、翻至对应页、高亮并滚动到本人；已绑定行被删除或姓名不再匹配时，不会回退定位到另一位同名嘉宾。
- 名单是共享会议内容，导入后先进入草稿，发布后所有旧链接同步。公开名单的职务和同名绑定不构成身份认证或报名资格。

## 验证

覆盖发布版本一致性、草稿隔离、停用、跨会议与跨工作人员权限、恶意输入、品牌域名限制、微信签名 URL、订单来源关联，以及手机/桌面真实组件渲染。
微信真机分享、开放标签及正式域名需要服务号配置和正式部署后验收；本地不宣称其已通过。

## 上线配置与验收

1. 执行 `pnpm prisma:generate`、`prisma migrate deploy`，构建 API、后台（包含独立邀请函入口）和小程序。此模块上线必须同步发布携带 invitationToken 的小程序报名页。
2. 配置 `INVITATION_PUBLIC_ORIGIN=https://guanchaohuiji.com`。配置品牌域名 HTTPS，将 `/i/`、`/invitation-assets/`、`/invitation-art/`、`/api/` 和 `/uploads/` 反向代理到同一个 API；不得将 `/i/` 重定向到第三方或后台域名。新版本静态资源部署需保留旧哈希文件，避免正在打开的页面加载失败。须执行新增名单绑定迁移 `20260930140000_invitation_roster_binding`。
3. 由服务器秘密管理系统注入 `WECHAT_OFFICIAL_APP_ID` 和 `WECHAT_OFFICIAL_APP_SECRET`，它们属于认证服务号，与小程序的 `WECHAT_APP_ID`、`WECHAT_APP_SECRET` 分开。配置服务号 IP 白名单、JS 接口安全域名、业务域名及域名校验文件。凭据不得填入会议内容或前端环境变量。
4. 按[微信开放标签文档](https://developers.weixin.qq.com/doc/service/guide/h5/opentag)确认账号资质与域名已获授权。`wx-open-launch-weapp` 使用小程序 appid 与报名页路径。外部浏览器使用小程序码降级。
5. 在角色管理单独勾选邀请函权限，再到邀请函「会议授权」分配人员。推荐邀约员只获 view、write 和指定会议授权；编辑员另获 content；发布负责人另获 publish；all 不代表跨会议授权，access 才能管理所有会议和授权。
6. 创建会议邀请函，选视觉，核对会议内容，上传公开名单，保存并发布，再生成个人邀请。同名时选择对应单位；核对变量替换后的分享标题。桌面提供品牌邀请地址二维码；微信内打开后使用右上角分享卡片。
7. 真机验收 iOS 和 Android 微信：卡片标题/封面/摘要、品牌 URL、点击进入小程序、支付后关联邀约、两条旧链接随发布同步、停用链接失效。

```nginx
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_cache off;
}
location ^~ /invitation-assets/ {
    proxy_pass http://127.0.0.1:3001;
    proxy_set_header Host $host;
}
location ^~ /invitation-art/ {
    proxy_pass http://127.0.0.1:3001;
    proxy_set_header Host $host;
}
```
