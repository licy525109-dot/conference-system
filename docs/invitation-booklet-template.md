# 观潮 · 会议长卷模板

## 来源与入口

根据项目根目录的 `邀请函样例参考.png`（402 × 5100）提取内容结构与排版。使用用户补充的横向潮汐纹（5032 × 1610）、竖向潮汐纹（1826 × 3353）、透明金色海浪纹（12500 × 6250）。前两张保留原图，海浪纹制作 2400 × 1200 的网页 JPEG，原素材不改动。

入口：专属邀请函 → 视觉与分享 → 封面设计 → 使用排版模板 → 观潮·会议长卷。

## 内容结构

1. 会议背景：现有邀请正文或富文本，保留已编辑内容。
2. 会议关键词：可编辑富文本，默认五项关键词。
3. 会议亮点：已有亮点优先；空内容提供四项示例。
4. 时间地点：当前会议的时间、会场、地址和会务联系方式。
5. 组织架构：按角色分组，支持同一角色多个单位。单位名称、标识、超链接均可编辑；标识支持 HTTPS、本地上传、素材库。空单位不公开展示。
6. 会议议程：所有日期连续展开。现有议程不替换；空议程使用“第一天 / 第二天 / 第三天”示例，不填入参考图的真实日期。
7. 小组讨论话题：八项可编辑示例，支持富文本、图片、超链接、排序和删除。可切换为原有标签页展示。
8. 拟邀嘉宾：沿用表格、名单排序、导入、搜索与本人定位；不复制参考图中的真实嘉宾。空名单显示持续更新状态。
9. 参会方式：可编辑邀请制说明。实际报名仍使用当前配置的小程序、外部 HTTPS 表单或隐藏入口。

已有嘉宾介绍和其他自定义模块追加保留。模块超过 24 个时拒绝应用并提示，不静默丢弃内容。再次点选已应用的长卷模板不改变已修改的章节、顺序、议题或显示状态。

## 视觉与发布

使用浅纸色、金色编号标题、短横线、淡海浪底纹及连续长卷排版。首屏读入当前会议标题、品牌、姓名、称谓与会议信息。保持现有色彩、字号、字体、动效、模块样式和章节导航配置入口。

选择模板只修改当前草稿。保存草稿不影响已生成链接；确认发布后，所有已有个人链接读取同一已发布配置。不创建会议记录、不自动发布、不修改生产嘉宾数据，不嵌入参考图中的固定二维码或组织标识。

## 人工验收

1. 选择模板，预览姓名、长会议名和手机首屏，核对原会议资料与报名入口保持不变。
2. 在会议内容里编辑关键词、组织架构、议题；上传标识后确认素材库可复用。调整模块顺序、隐藏一章再预览。
3. 保存草稿、刷新后台，核对文字、名单与模块保留；再次应用模板，核对已编辑内容未覆盖。
4. 确认发布，打开两条原个人链接，核对正文同步且姓名各自独立。微信真机卡片及字体体验仍需真实设备验收。

- 后端单元测试 534 项、整个 workspace 类型检查、共享包构建、后台生产构建和 `git diff --check` 通过。浏览器测试使用接口夹具，不等同于生产业务数据或微信真机验收。
- 视觉证据位于 `output/playwright/invitation-booklet-*`，不纳入生产发布文件。
