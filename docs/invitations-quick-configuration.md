# 邀请函快速配置

本次仅更新邀请函的配置与展示，不修改现有会议、受邀人、支付或订单数据，继续沿用邀请函读写、发布和素材权限。

## 会议议程

- 在“会议内容 → 会议议程”按日期编辑。主行只保留时段和议题，嘉宾、地点及头像按需展开。
- 支持添加日期、修改日期、添加、复制、上下排序和删除议程。重命名为已有日期需确认合并。
- “批量录入”可粘贴表格或上传 5MB 内的 XLSX、XLS、CSV、TSV。自动识别列，支持人工调整映射和缺省日期。
- 先预览再导入。缺失议题、超长字段、不安全的头像地址、重复列映射和超过 150 条均阻止导入，不静默截断。
- 默认追加；替换当前日期需确认，保留其他日期、头像和原日期顺序。
- 原议程字体、字号、行距、间距、按天切换 / 连续展示仍在“样式”页。打开编辑器本身不改变旧议程内容和排版。

## 时间地点

- 默认跟随会议信息，兼容已有邀请函。
- 切换“自定义条目”后，可增删、排序、自定义标题、图标、多行内容和安全链接。首次切换以现有信息生成条目。
- 自定义条目为空时，公开页面和导航隐藏该模块，不回退到旧会议字段。
- 自定义条目不会改动封面上的会议时间、地点。

## 组织画布

- “组织架构 → 自由画布”首次根据现有组织单位生成分组排布；Logo 素材保持不变。
- 可拖拽位置、拖动角点缩放，也可输入百分比坐标与尺寸；支持键盘方向键、对齐、辅助网格和撤销 / 重做。
- 可添加分组文字，调整字号、字体、颜色和加粗；使用已上传的自定义字体。
- 新增文字默认接在已有对象下方，必要时扩展画布。切回并排 / 逐行模式保留画布布局。
- “一键排齐”需确认，保留单位素材并重新生成分组布局。单位素材、名称、链接仍在下方原有表单编辑。

## 联系会务组

- 在“添加模块”菜单添加“联系会务组”，可编辑标题、显示、模块顺序和模块样式。
- 最多 20 位联系人，各自填写姓名、负责事项、电话、微信号、备注及微信 / 群二维码。
- 支持联系人排序、删除。所有内容选填；空联系人及空模块不公开展示。
- 嘉宾端提供安全的拨号链接与微信号复制；浏览器不支持复制时提示长按微信号。二维码支持上传或素材库选择。
- 字段按纯文本显示，图片和链接继续使用既有白名单清洗。

## 验收边界

保存草稿后点击“发布更新”，所有已有专属邀请链接读取同一已发布版本，保留各自受邀人姓名。不自动添加会务模块或重排真实会议内容。

本地与生产静态资源的合成数据浏览器回归不代表真实工作人员登录、实际会务二维码识别或微信真机拨号 / 复制验收。这些需在实际会议上由工作人员确认。
