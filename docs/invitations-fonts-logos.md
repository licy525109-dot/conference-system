# 邀请函自定义字体、组织标识与议程排版

## 配置入口

- 字体：专属邀请函 → 视觉与分享 → 字体与字号。封面设计中的「上传 / 选择字体」和定位画布的「上传字体」也可直达。
- 组织标识：会议内容 → 组织架构 → 内容。单位使用相同的「角色 / 分组」时归入同一行组，例如多个「联合主办」。
- 议程排版：会议内容 → 会议议程 → 样式。

## 自定义字体

- 沿用鉴权的邀请函素材上传与素材库，支持 WOFF2 / WOFF / TTF / OTF，每个文件不超过 5MB。上传前须确认网页使用授权；不能通过页面配置更改服务器权限。
- 上传后自动存入素材库并应用，默认统一封面、正文与模块字体。可修改字体名称，或关闭统一字体，继续保留各处独立样式。
- 封面动态文字的字体下拉框可选择当前上传字体。富文本编辑器也可选该字体，仅为所选文本设置字体。未配置上传字体时，保留原有内置字体。
- 自定义富文本仅保存受控的 `var(--invite-custom-font)` 标记。不能借字体配置注入任意 CSS 变量或可执行样式。
- 页面字体与封面、正文的自定义字体选择可以独立存在。异步加载完成后，封面重新检查文字尺寸，保证长姓名仍能落在定位框内。加载失败保留系统字体回退。
- HTTPS 字体需允许浏览器跨域读取；本地上传走本站素材。已烘焙到封面图片中的文字不能用网页字体替换。

## 多单位 Logo

- 每个单位独立上传或选择一个标识，支持单位名和超链接；多项相同分组自动并排。
- 展示方式可选并排或逐行。桌面每行 2 / 3 / 4 个；窄屏和手机预览自动按 2 列换行，逐行模式为 1 列。
- 统一高度可调 32–96px，默认 56px。系统使用等宽等高展示框和 `object-fit: contain` 等比缩放，不裁切或拉伸原始标识。不同长宽比例的实际图形轮廓可能仍有差异。
- 可以隐藏单位名称；无图的纯文字单位仍保留，避免内容消失。空单位不公开展示。
- 添加单位时沿用当前展开的分组，未选择分组时默认「主办单位」。保留原有 20 项上限、项目排序和删除。

## 议程排版

- 标题默认 14px，时间、嘉宾信息和地点默认 12px。可分别设置标题 12–24px、信息 10–18px；桌面、手机和编辑器预览均使用设置值。
- 可设置标题字重、行距与每条议程的上下间距；背景、文字和强调色仍在该模块的样式面板内设置。不会修改其他模块或议程内容。
- 日期展示可跟随模板、按天切换或连续展示。原长卷模板默认连续展示，其他模板默认按天切换；可独立覆盖。
- 恢复主题样式一次还原议程排版与模块颜色、间距，保留议程内容和非排版设置。

## 关键词与小组讨论备注

- 会议关键词自动采用编号陈列：电脑三列、手机两列，内容仍来自原富文本。模块样式中的「文字展示形式」可切回正文，或为其他图文模块选择关键词陈列。关键词按中点、竖线和段落换行划分，原富文本仍保留，正文模式可恢复内嵌格式和链接。
- 小组讨论内容面板提供「显示讨论备注」、长文本「讨论备注」和「使用共创说明」。开关独立于备注内容，隐藏不删除文字。
- 新建长卷模板默认填入用户提供的三行说明。现有已发布会议不批量写入备注，需要在后台选择使用共创说明或自行编辑后发布。

## 保存与人工验收

1. 进入字体与字号，确认字体授权，上传字体；核对名称、预览、素材库中存在该字体。错误格式和超过 5MB 的文件应拒绝。
2. 开启统一字体，核对封面、标题和正文；关闭统一字体，在画布或富文本内单独选上传字体，保存后刷新确认保留。
3. 组织架构内增加几个相同分组的单位，上传长条、方形和竖形标识；调整每行数量、高度与名称显隐，手机预览应无横向溢出。
4. 在会议议程的样式页调整标题字号、时间与嘉宾字号、字重、行距、条目间距和日期展示，检查手机预览，保存刷新后设置仍应保留。
5. 预览、保存并发布后，打开原个人邀请链接确认最新字体、标识和议程排版。字体授权、真实中文字体文件和微信真机效果仍由使用者验收。

本次仅更新展示配置与共享文档契约，不创建或修改生产会议、嘉宾、订单，不新增数据库迁移或改变支付和鉴权逻辑。未发布的草稿不影响原个人链接。
