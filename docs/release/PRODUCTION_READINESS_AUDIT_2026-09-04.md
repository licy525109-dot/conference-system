## 用户必须完成

### 1. GitHub 仓库

- 确认 `main` 启用分支保护，至少要求部署 preflight 成功后才允许合并。
- 以后如生产机重装或 SSH 主机密钥变化，再在 Actions repository variable 新增或更新 `BAOTA_HOST_FINGERPRINT`。

### 2. 微信公众平台和商户平台

- 确认小程序 AppID 已绑定当前微信支付商户号，API v3、商户证书/私钥和平台公钥处于有效状态。
- 为报名成功、支付成功、会务安排更新、退款状态更新分别选取订阅消息模板，对应 `WECHAT_SUBSCRIBE_TEMPLATE_REGISTRATION_SUCCESS`、`WECHAT_SUBSCRIBE_TEMPLATE_PAYMENT_SUCCESS`、`WECHAT_SUBSCRIBE_TEMPLATE_GUEST_SCHEDULE_UPDATED`、`WECHAT_SUBSCRIBE_TEMPLATE_REFUND_STATUS_UPDATED`。
- 提供模板 ID 和每个关键词的字段名映射；这些不是密钥，可以录入后台或服务器配置。
- 在微信公众平台“付费管理”检查手机号快速验证试用量/套餐余量，额度不足时购买套餐；首次登录由用户点击醒目的一键绑定按钮授权，不做无感获取。
- 确认小程序 request 合法域名和支付/退款回调 HTTPS 域名已配置。

### 3. 业务规则

- 确认商城退货入库、发票红冲和退款先后顺序；未确认前保持商城退款关闭。
- 确认退款截止时间和面向用户展示的退款说明。

### 4. 共同真机验收

- 微信手机号一键绑定成功，后台敏感权限账号可查看完整号码并产生审计记录。
- 用户主动允许四类订阅消息，后台任务状态与微信实际到达一致。
- 用 0.01 元真实订单完成预下单、支付回调、报名生成、库存转换和消息通知。
- 发布一条包含时间、地点、桌号/桌长或分享内容的会务安排，消息列表与完整日程均显示真实字段。
- 发起并审批一笔真实退款，核对微信到账、退款回调、订单状态、可退余额、名额恢复和通知。
- 部署后确认 `/api/health/ready`、Admin、H5、小程序和 Nginx 均正常，再开放正式报名。
