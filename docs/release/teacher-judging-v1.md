# 绘本舞蹈教师赛课评分系统 V1.0

## 后台入口和岗位

登录观潮会集后台，在「会议管理 → 赛课评审」选择或新建赛事。新建时选择「联排测试」或「正式赛事」。每场赛事独立保存配置、原始评分单与确认版本。新建赛事需要全局范围的配置账号。

在「系统管理 → 角色权限」授予所需岗位权限。各岗位均需 `judging:view`。配置人员另需 `judging:config`，场控需要 `judging:floor`，内部成绩查看需要 `judging:results`。调分人员需要成绩查看和 `judging:adjust`，确认人需要成绩查看和 `judging:confirm`。工作人员按职责授予 `judging:export` 或 `judging:publish`。会议授权账号还需由全局赛事管理员在「赛前设置 → 工作人员授权」加入指定赛事。正式确认人须由有账号管理权限的管理员选定，并关联王红丽老师已验证手机号的实名微信用户。

## 赛前配置

1. 在「赛前设置 → 名单与排场」录入或导入选手、教室、评委、场次和优秀奖名单。可下载 Excel 后填写，也可导入现有报名人员。报名导入需要该会议的名单导出权限。按抽签顺序生成排场后核对每位教师的课堂和 TED 场次。
2. 在「手机页面设计」配置封面、主办方标志、四种颜色、字号、圆角、标题、按钮、回执及照片、机构和任务的显示开关。可切换四种评委身份试填，保存后手机端生效。
3. 在「评分表与规则」录入专业、大众及 TED 评分细则。体验与观察可分别配置量表。金金老师协调确认正式题目、缺项处理、最低有效份数及显示与同分精度。正式赛需要确认量表。现场改版后，已开放场次和其补交沿用原版。
4. 在「工作人员授权」核对场控、调分、导出岗位及最终确认人。每位评委占一行，填写独立编号、姓名、机构、评委身份。课堂评委填写教室，TED 专家按 TED 排场分配。重名者保留各自编号和机构。

## 发布入口和扫码评分

场控在「操作首页 → 评委评分入口」点击「发布评分入口」。这里直接展示二维码，可下载图片、复制链接或打开评分页。把同一个链接或二维码发给所有专业讲师、大众评委和 TED 专家，全程共用。场控可提前发码，再在「现场收分」开始赛事并开放当场评分。停用入口立即撤销旧链接和手机上的本次登录，再次发布会生成新的二维码。

嘉宾在微信或手机浏览器扫码打开 H5，输入名单上的完整姓名。唯一匹配直接进入评分。同名时只显示匹配的编号和机构，选中本人记录后，系统按名单身份和当前开放场次提供评分表。未开放的场次会提示等待。提交后显示回执，重复打开可查看本人任务。「切换姓名」适用于多人共用测试设备。

## 收分、确认与公布

场控按教室开放或截止评分，查看各席别实到、待交和有效份数，在名单上登记到场、缺评与补交。评委在 H5 评分页核对教师和场次，提交成功后可回看时间和本人任务。相同任务重试返回同一回执。

在「成绩与颁奖 → 成绩与复核」按教师查原单、分项和有效份数。更正原单或直接调总分均需填写原因。系统重算名次和奖项，已有总分调整的原单更正后须再次核对。全部同分时，登记复赛依据和裁定顺序。核对 15 位选手、19 位优秀奖及 13 所教学示范校后送审。王红丽老师在本人后台确认整份名单，版本随即锁定。后续修订生成新的待确认版本。

「颁奖与发布」可从确认版本勾选字段导出颁奖名单。12 月 15 日为内部复核，12 月 16 日起由获授权岗位选择字段并手动公布。公开页只读取已发布的确认版。原单和复核对照表分别从「成绩与复核」导出。

## 发布和验收

新增迁移 `20261124160000_teacher_judging` 创建赛事、原单、确认版本和审计四张表。使用仓库既有生产流水线执行备份、迁移、构建、服务重启与健康检查。生产发布后核验管理端入口、评审模块静态资源、后台未登录访问与公开名单权限。评分 H5 与后台、API 一同构建上线。姓名入口使用现有赛事配置存储，无额外数据库迁移。

数据库联排入口为 `tests/e2e/judging.integration.ts`。该测试仅接受本地独立数据库 `judging_test`，使用虚构人员覆盖 510 份原单和跨奖项调分。CI 负责迁移、构建并运行此测试。

如需回退，按项目发布流程切回本次部署前的应用提交并恢复对应静态文件。保留四张新增表及已经收到的评分单，避免恢复旧数据库时覆盖比赛期间的新记录。
