# 绘本舞蹈教师赛课评分系统 V1.0

## 后台入口和岗位

登录观潮会集后台，在「会议管理 → 赛课评审」点击「新建赛事」，填写赛事名称、教室数量和每间教室的课堂轮数。创建后直接进入「名单与排场」。每场赛事独立保存二维码、名单、原始评分单与确认版本。已有内部测试场标为「仅内部使用」，成绩只供内部核对。新建赛事需要全局范围的配置账号。

在「系统管理 → 角色权限」授予所需岗位权限。各岗位均需 `judging:view`。配置人员另需 `judging:config`，场控需要 `judging:floor`，内部成绩查看需要 `judging:results`。复核分场成绩和调分需要成绩查看和 `judging:adjust`，锁定全天成绩需要成绩查看和 `judging:confirm`。工作人员按职责授予 `judging:export` 或 `judging:publish`。会议授权账号还需由全局赛事管理员在「赛前设置 → 工作人员授权」加入指定赛事。

## 赛前配置

1. 在「赛前设置 → 名单与排场 → 教室与轮次」调整每间教室的名称、课堂轮数和评委配额。录入或导入选手与评委后，在「场次」点击「按选手顺序排场」。系统按轮次依次使用每间仍有空位的教室，并按名单顺序生成 TED 场次。空位可以保留。时段不足时会提示增加教室或轮数。核对教室、轮次和时间后点「保存赛前配置」。名单可下载 Excel 模板填写，也可导入已有报名人员。报名导入需要该会议的名单导出权限。
2. 在「操作首页」的二维码旁点「设计评分入口」，或进入「赛前设置 → 评分页面设计」。在「扫码首页」选绘本对页、横幅海报或简洁文字，设置配色、标题、欢迎语、封面、标志和按钮。右侧可切换手机、电脑及重名选择预览。「评分表与回执」可设置交分按钮、回执和显示字段并按评委身份试填。点「保存页面设计」后，评委重新打开原二维码或链接即可看到新版。
3. 在「评分表与规则」选择一个评委类型，编辑其评分细则。点「新增评委类型」填写名称并选择计分方式，也可以勾选使用新表的评委。总部讲师、体验席、观察席和 TED 专家都可以选中后点「删除当前类型」。已有评委时，按弹窗提示转入其他类型，赛前也可明确选择将这些评委移出本赛事名单。点「保存评分表与规则」生效。现场修改时点「对尚未开放的场次启用新版评分表」，已开场和补交继续用原表。金金老师协调核对正式题目、缺项处理、最低有效份数及显示与同分精度。正式赛需要确认量表。
4. 在「工作人员授权」选择本场后台账号，点「保存赛事授权」。评委在「名单与排场 → 评委」录入，每位评委占一行，填写独立编号、姓名、机构、评委身份。课堂评委填写教室，TED 专家按 TED 排场分配。重名者保留各自编号和机构。

在「教室与轮次」的「评分开放方式」一栏，给每间教室选择「逐轮开放」或「全部轮次」。开始现场评分时，选了「全部轮次」的教室会同时开放首个场别的课堂。若同一教室横跨上下午，场控在下午选中该教室的下午场次，点「开放本教室全部轮次」。逐轮开放的教室由场控点「开放本场」。

在「名单与排场 → 选手」添加或编辑选手，点「本地上传照片」，看到预览后点「应用到草稿」，再点「保存赛前配置」。支持 2 MB 以内的 JPG、PNG、WebP，照片选填。

在「评分表与规则 → 选手与评委共用说明」填写「评审说明」和「评分规则」，点击「保存评分表与规则」。扫码首页可在输入姓名前展开阅读。评分页显示当前场次使用的版本。

## 发布入口和扫码评分

场控在「操作首页 → 评委评分入口」点击「发布评分入口」。这里直接展示二维码，可下载图片、复制链接或打开评分页。把同一个链接或二维码发给所有专业讲师、大众评委和 TED 专家，全程共用。场控可提前发码，再在「现场收分」开始赛事并开放当场评分。停用入口立即撤销旧链接和手机上的本次登录，再次发布会生成新的二维码。

嘉宾在微信或手机浏览器扫码打开 H5，输入名单上的完整姓名。唯一匹配直接进入评分。同名时只显示匹配的编号和机构，选中本人记录后，系统按名单身份和当前开放场次提供评分表。未开放的场次会提示等待。提交后显示回执，重复打开可查看本人任务。「切换姓名」适用于多人共用测试设备。

## 收分、确认与公布

赛前在「名单与排场 → 场次」核对「场别」。自动排场默认课堂为上午场、TED 为下午场，可逐行修改，也可在 Excel 场次表填写「上午场」或「下午场」。点击「保存赛前配置」生效。

1. 上午结束时，场控在「现场收分」核对已交份数，点「结束上午场评分 → 结束并进入复核」。系统关闭上午场的普通评分和此前的补交入口。下午的排场和开关独立，TED 由场控手动开放。
2. 组委会进入「成绩与颁奖 → 成绩与复核 → 上午场复核」。按选手核对本场的有效份数、分项和原单。展开「待处理明细」可找出缺哪位评委的评分单。漏交请场控在对应场次登记补交或缺评原因，待核原单点「查看 / 更正」并填写依据。待处理数归零后点「完成上午场复核」。
3. 下午结束时，用「结束下午场评分」和「下午场复核」完成同一流程。上午复核可与下午收分同时进行。确需修改已复核的原单时，点击「重新复核」并填写原因，处理后再次确认本场。
4. 两场均显示「已复核」后，选「全天成绩」，核对总分、名次和奖项，有锁定权限的运营点「确认并锁定全天成绩」，在弹窗点「确认锁定」。系统保存该版本和实际操作账号。只排了半天的赛事只需复核实际有排场的场别。分场复核属于内部操作。

若误点结束，场控可在该场仍为「待复核」时点「恢复收分」，填写原因，再开放需要继续评分的教室或 TED，已交的原单仍可查阅。

TED 环节开始时，场控进入「现场收分」，点「开放全部 TED」并确认。所有已排的 TED 选手会同时开放。专家在手机上点「选择评分选手」，按自己需要的顺序逐人评分，每人各有一份回执。TED 环节结束时点「截止全部 TED」。

场控可以选中某教室的场次，切换「全部轮次评审」。开启会同时开放该教室全部已排选手，切回逐轮会截止该教室其他正在进行的轮次，当前场次保留原状态。全轮次教室可以一键开放或截止。收分表显示各席别实到、待交和有效份数，可在名单上登记到场、缺评与补交。相同任务重试返回同一回执。

在「成绩与颁奖 → 成绩与复核」按教师查原单、分项和有效份数。更正原单或直接调总分均需填写原因。系统重算名次和奖项，已有总分调整的原单更正后须再次核对。全部同分时，登记复赛依据和裁定顺序。新建赛事按实际名单核对。有规定名额时，在赛前的「评分表与规则 → 更多设置」填入优秀奖人数和示范校数量。原有正式赛保留 19 位、13 所的核对要求。锁定后若需更正，点「建立修订版」，修改后再次核对并锁定。

「颁奖与发布」可从确认版本勾选字段导出颁奖名单。12 月 15 日为内部复核，12 月 16 日起由获授权岗位选择字段并手动公布。公开页只读取已发布的确认版。原单和复核对照表分别从「成绩与复核」导出。

## 发布和验收

新增迁移 `20261124160000_teacher_judging` 创建赛事、原单、确认版本和审计四张表。使用仓库既有生产流水线执行备份、迁移、构建、服务重启与健康检查。生产发布后核验管理端入口、评审模块静态资源、后台未登录访问与公开名单权限。评分 H5 与后台、API 一同构建上线。姓名入口使用现有赛事配置存储，无额外数据库迁移。

数据库联排入口为 `tests/e2e/judging.integration.ts`。该测试仅接受本地独立数据库 `judging_test`，使用虚构人员覆盖 510 份原单和跨奖项调分。CI 负责迁移、构建并运行此测试。

如需回退，按项目发布流程切回本次部署前的应用提交并恢复对应静态文件。保留四张新增表及已经收到的评分单，避免恢复旧数据库时覆盖比赛期间的新记录。
